# Smart Solar Agri-Hub: Multi-Agent Swarm & Control Infrastructure

## Overview
A decentralized multi-agent system integrating IoT telemetry, adaptive microgrid control logic, and automated agricultural utility management (cold chain preservation and precision irrigation).

## Preexisting Work & Attribution
* **Preexisting Work**: Baseline physical microgrid architecture, hardware component integration (ESP32/solar PV setup), and baseline hardware documentation built prior to the sprint.
* **Sprint Work**: Multi-agent alignment algorithms, edge consensus protocols, fault-tolerance control loops, and research report documentation developed during the hackathon.

## Repository Structure
* `/firmware`: Embedded code for microcontrollers (ESP32/Arduino).
* `/dashboard`: Web interface and telemetry dashboard scripts.
* `/docs`: System architecture diagrams and technical documentation.

## Setup & Execution
1. Flash firmware to ESP32 microcontrollers using standard Arduino IDE settings.
2. Launch the telemetry dashboard to inspect edge-agent communications.
